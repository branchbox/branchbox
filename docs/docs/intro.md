# Welcome to BranchBox

BranchBox is a distributed development environment orchestrator that manages git worktrees and devcontainers.

This documentation captures the installation paths, CLI workflows, architectural context, and contributor guidance for operating in distributed feature environments.

## Getting Started

- **New to BranchBox?** Start with the [Installation Guide](getting-started/installation.md) for installation and first-run instructions.
- **Setting up your workstation or devcontainer?** Jump to [Development Environment](getting-started/development.md).
- **Want to understand how specs, adapters, and modules work together?** Visit the [Architecture Overview](architecture.md) and [Specs Workflow](reference/specs-workflow.md) chapters.
